# superfofa 2.2

## 修复

- **适配平台双请求头鉴权**：部分 MCP 平台在 `Authorization: Bearer <Token>` 之外还要求 `X-MCP-Key`。系统配置新增「MCP Key」输入项，留空则不发送该请求头，兼容只认 Bearer 的平台
- **修正 MCP 查询结果解析**：按平台实际返回的 `columns` + `rows`（对象数组）生成表格。此前只认官方 REST 的 `fields` + `results`，会出现「命中数正常但列表为空」
- **统计去重数**：取平台返回的 `distinct`，不再用 TopN 条数代替

## 优化

- 平台前置防护（Cloudflare / WAF）返回网页时，提示会直接说明「请补填 MCP Key」，不再是「解析响应失败」

## 使用方式（fofa.as3.cc.cd 示例）

| 配置项 | 值 |
|---|---|
| API 地址 | `https://fofa.as3.cc.cd/mcp` |
| 接口协议 | 自动识别 或 MCP 平台 |
| MCP Key | `mcp_xxx`（平台网关 Key，请求头 `X-MCP-Key`） |
| 账号 Key | `fofa_mcp_xxx`（平台查询 Token，请求头 `Authorization: Bearer`） |
