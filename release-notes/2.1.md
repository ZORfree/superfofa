# superfofa 2.1

## 新增

- **MCP 平台接入**：系统配置新增「接口协议」（自动识别 / 官方 REST / MCP 平台），可直接对接第三方 FOFA 兼容平台（如 `https://host/mcp`）。API 地址以 `/mcp` 结尾时自动按 MCP 协议通信
- **MCP 能力覆盖**：查询、分页导出、聚合统计、账号检测（走额度接口，不消耗查询次数）均支持 MCP 平台

## 优化

- **Token 校验放开**：FOFA 用户 Token 不再强制三段式 JWT 校验，第三方平台 Key（如 `fofa_mcp_…`）可原样保存并作为 `Authorization: Bearer` 发送，不再误报「Token 格式不正确」
- MCP 结果解析兼容数组行与对象行两种格式，列名自动对齐

## 限制

- 主机画像（host 详情）仅官方 REST 提供，MCP 模式下会提示不支持

## 使用方式

1. 系统配置 → API 地址填 `https://fofa.as3.cc.cd/mcp`，接口协议选「自动识别」或「MCP 平台」，保存
2. 配置页 → 添加账号，Key 填 MCP Token（邮箱留空即可），检测通过后入库
3. 正常查询、导出、统计
